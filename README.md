1. Clone the Repository
   Open your terminal or command prompt and clone the project:
      git clone https://github.com/danaiaxx/vet-system.git
      cd vet-system

2. Install Flask
   Install the necessary dependency, Flask, directly into your system's Python environment:
      python -m pip install flask

3. Run the Application in VS Code
   Open the project folder (vet-system) in Visual Studio Code (VS Code).
   Open your main application file (app.py).
   Click the "Run" button (or press F5).

4. Access the Application
   Once the application starts, VS Code will show a link in the terminal (example: http://127.0.0.1:5000/).
   Copy this link from the terminal output.
   Paste it into your web browser to view the application.

🛠 Project Details
Backend: Python, Flask
Database: SQLite3
Dependencies: Only flask is manually installed in the initial setup.
