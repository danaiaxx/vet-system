# 🐾 Vet System (Flask Application)

A simple web application for managing a veterinary clinic's operations, built using the **Flask** framework. This project is set up for a quick and easy local run.

## 🚀 Quick Start Guide

Follow these steps to clone the repository and run the application locally.

### 1. Clone the Repository

Open your terminal or command prompt and clone the project:

```bash
git clone https://github.com/danaiaxx/vet-system.git
cd vet-system
````

### 2\. Install Flask

Install the necessary dependency, **Flask**, directly into your system's Python environment:

```bash
python -m pip install flask
```

### 3\. Run the Application in VS Code

1.  Open the project folder (`vet-system`) in **Visual Studio Code (VS Code)**.
2.  Open your main application file (e.g., `app.py`).
3.  Click the **"Run"** button (or press `F5`) in the VS Code interface.

### 4\. Access the Application

1.  Once the application starts, VS Code will show a link in the terminal (example: `http://127.0.0.1:5000/`).
2.  **Copy this link** from the terminal output.
3.  **Paste it into your web browser** to view the application.

-----

## 🛠 Project Details

  * **Backend:** Python, Flask
  * **Database:** SQLite3
  * **Dependencies:** Only `flask` is manually installed in the initial setup.
